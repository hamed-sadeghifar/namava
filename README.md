# 🎬 Namava Landing Page Clone

🔗 Live Demo:
https://hamed-sadeghifar.github.io/namava

A fully responsive clone of the **Namava** homepage built with **React** and **Tailwind CSS**.

This project focuses on recreating the first page of the Namava website with a clean component-based architecture while keeping the design as close as possible to the original.

> **Note:** This project is developed for educational and portfolio purposes only.

---

## ✨ Features

- 🎥 Pixel-perfect recreation of the Namava landing page
- 📱 Fully Responsive (Mobile, Tablet & Desktop)
- ⚛️ Built with React Functional Components
- 🎨 Styled using Tailwind CSS
- 🧩 Reusable and modular component architecture
- 🚀 Fast development environment with Vite
- 💻 Clean and maintainable code structure

---

## 🛠️ Technologies Used

- React
- Tailwind CSS
- JavaScript (ES6+)
- Vite

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/namava-clone.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
